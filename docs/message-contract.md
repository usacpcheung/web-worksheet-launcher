# Idea02 Message Contract (v1)

This document defines the **hash parameters** used to launch the
OIDC-protected popup worksheet page and the **postMessage payload** used
to return results back to the parent app.

------------------------------------------------------------------------

## 1) Terms

-   **Parent app**: the original HTML/JS page that generates questions
    and opens the popup.
-   **Popup / Renderer**: the OIDC-protected page (`render.html`) that
    renders questions, calls the rewrite API, and sends results back.
-   **RID**: request id generated by parent to match responses (`rid`).

------------------------------------------------------------------------

## 2) Launch URL (Parent ➜ Popup)

### 2.1 Render page URL

The popup render page is hosted on your server, protected by Apache
OIDC:

-   `https://<OIDC_HOST>/worksheet/render.html`

### 2.2 Hash parameters (required)

The parent opens the popup using hash params:

-   `w` (required): base64url-encoded JSON payload (worksheet
    definition)
-   `rid` (required): request id string generated by parent
-   `returnOrigin` (required):
    `encodeURIComponent(window.location.origin)` from the parent page

Example:

https://`<OIDC_HOST>`{=html}/worksheet/render.html#w=`<BASE64URL_JSON>`{=html}&rid=`<RID>`{=html}&returnOrigin=`<ENC_PARENT_ORIGIN>`{=html}

------------------------------------------------------------------------

## 3) Worksheet Payload (JSON) --- `w` decoded

### 3.1 Schema (v1)

``` json
{
  "v": 1,
  "title": "Quick Check",
  "q": [
    "Question 1",
    "Question 2"
  ],
  "rewrite": true
}
```

### 3.2 Rules

-   `v` MUST be `1`
-   `q` MUST be an array of strings, length **1..5**
-   `title` is optional (string)
-   `rewrite` is optional (boolean) --- reserved for future toggles

------------------------------------------------------------------------

## 4) postMessage Return (Popup ➜ Parent)

### 4.1 Message name

Popup sends exactly one message type to return answers:

-   `type: "worksheetResult"`

### 4.2 Payload schema

``` json
{
  "type": "worksheetResult",
  "rid": "rid_123",
  "worksheet": {
    "v": 1,
    "title": "Quick Check",
    "q": ["Question 1", "Question 2"]
  },
  "answers": [
    { "index": 0, "question": "Question 1", "raw": "student text", "rewritten": "rewritten text" },
    { "index": 1, "question": "Question 2", "raw": "", "rewritten": "" }
  ],
  "meta": {
    "sentAt": "2026-03-02T12:34:56.000Z"
  }
}
```

### 4.3 Notes

-   `answers[].raw` is what the student typed/spoke before rewrite
-   `answers[].rewritten` is the rewrite output (may be empty if not
    rewritten)
-   `meta.sentAt` is ISO-8601 timestamp

------------------------------------------------------------------------

## 5) Security Requirements

### 5.1 Parent-side validation (MUST)

The parent app MUST validate:

1)  `event.origin` equals the trusted popup renderer origin\
    e.g. `https://<OIDC_HOST>`
2)  `event.data.type === "worksheetResult"`
3)  `event.data.rid` matches the `rid` used when opening the popup

If any check fails, ignore the message.

### 5.2 Popup-side send rule (MUST)

The popup MUST send the result using:

-   `targetOrigin = decodeURIComponent(returnOrigin)`

Do NOT use `"*"` unless you fully accept any receiving origin.

------------------------------------------------------------------------

## 6) Compatibility Notes

-   This mechanism does **not** involve CORS because it uses
    `window.postMessage`.
-   Popup must be opened via `window.open()` (recommended) to ensure
    `window.opener` exists.
-   If the parent page uses `noopener`, `window.opener` may be `null`
    and results cannot be sent back.

------------------------------------------------------------------------

## 7) Future Extensions (non-breaking)

Potential future additions:

-   Voice input metadata (confidence, interim transcripts)
-   Autosave/resume token
-   Streaming rewrite UX
-   Optional `type: "worksheetReady"` handshake message for advanced
    initialization mode
